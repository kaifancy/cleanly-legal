# Cleanly Legal Pages

Static, bilingual legal pages for GitHub Pages.

## Publish

1. Create a public GitHub repository named `cleanly-legal`.
2. Upload everything in this folder to the repository root, preserving the folders.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then **main** and **/(root)**.
5. Save and wait for the Pages URL to appear.

Default URLs after publishing:

- Chinese privacy policy: `https://USERNAME.github.io/cleanly-legal/privacy/`
- English privacy policy: `https://USERNAME.github.io/cleanly-legal/privacy/en/`
- Chinese terms: `https://USERNAME.github.io/cleanly-legal/terms/`
- English terms: `https://USERNAME.github.io/cleanly-legal/terms/en/`

Replace `USERNAME` with the GitHub account name.
